# Hospital Network System

## Project Overview
This project demonstrates a hospital network infrastructure designed using Cisco Packet Tracer.

## Features
- Multiple departments connected through VLANs
- Router configuration
- DHCP and DNS servers
- Secure communication
- Wireless access
- Server room connectivity

## Tools Used
- Cisco Packet Tracer

## Network Components
- Routers
- Switches
- PCs
- Servers
- Access Points
